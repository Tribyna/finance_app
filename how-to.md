# Как добавить новую транзакцию в finance_app

## Предусловия

- Python 3.9 или новее установлен
- Репозиторий `finance_app` склонирован
- Виртуальное окружение создано и активировано
- Зависимости из `requirements.txt` установлены
- Есть учётная запись пользователя

## Шаги

1. Запустите приложение:

python main.py

2. Войдите под своим именем пользователя и паролем.

3. В левой панели нажмите кнопку **«💰 Доход»** или **«💸 Расход»**.

4. В открывшемся окне в поле **«Сумма»** введите число:

5. В поле **«Выберите категорию»** выберите значение из выпадающего списка.

6. В поле **«Описание»** при необходимости введите комментарий.

7. Нажмите кнопку **«➕ Добавить доход»** или **«➖ Добавить расход»**.

## Результат

Окно добавления закроется. На дашборде обновится **«ТЕКУЩИЙ БАЛАНС»** и блок **«ДОХОДЫ»** или **«РАСХОДЫ»**. Новая запись появится на странице **«📜 История»**.

Если данные не сохранились — под полями появится красное сообщение с причиной: «Сумма должна быть положительной», «Выберите категорию» и т. п.
