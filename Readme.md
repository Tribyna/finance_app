# Finance App

Приложение для учёта личных финансов с графическим интерфейсом.
Позволяет записывать доходы и расходы, отслеживать баланс и анализировать
траты по категориям — без необходимости вести таблицы вручную.

Подойдёт тем, кто хочет контролировать свой бюджет в удобном
настольном приложении, а не в браузере или мобильном банке.

## Возможности

- Добавление, редактирование и удаление доходов и расходов
- Просмотр текущего баланса и истории операций
- Разбивка трат по категориям
- Хранение данных в локальной базе данных

## Требования

- Python 3.9 или новее
- ОС: Windows, Linux, macOS
- Около 50 МБ свободного места
- Все зависимости из `requirements.txt`

## Установка

1. Клонируйте репозиторий:

git clone https://github.com/Tribyna/finance_app.git
cd finance_app


2. Создайте виртуальное окружение и активируйте его:

python -m venv venv
source venv/bin/activate

В Windows вместо последней команды: `venv\Scripts\activate`

3. Установите зависимости:

pip install -r requirements.txt

4. Запустите приложение:
python main.py


## Пример использования

После запуска откроется главное окно приложения.
Чтобы добавить расход:

1. Нажмите кнопку «Добавить операцию».
2. Выберите тип «Расход».
3. Введите сумму и категорию (например, «Продукты»).
4. Нажмите «Сохранить».

Новая запись появится в списке операций, а баланс пересчитается автоматически.
